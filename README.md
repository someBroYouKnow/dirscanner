# Folder Scanner v1.0.0

A tool to find and delete specific folders recursively.

## Features
- Browse and select any folder on your computer
- Search for folders by name (e.g., "node_modules")
- Calculate total size of found folders
- Option to delete all found folders with confirmation

## How to Use
1. Download `folder_scanner.exe`
2. Double-click to run
3. Select a folder to scan
4. Enter the folder name to search for
5. Review results and optionally delete folders

## Requirements
- Windows 10/11 (64-bit)

## Safety
- Always asks for confirmation before deleting
- Shows exactly what will be deleted
- Handles errors gracefully
